| Boundary | Description |
|----------|-------------|
| CLI prompt → filesystem | User-entered path is untrusted input crossing into file-open/read code (process_uploaded_file) |
| chat file content → parsers | Crafted chat exports are untrusted data entering parsing logic |
| installed package → runtime | What the wheel contains is what executes — web-app patterns must not ship (QUAL-04) |

|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Information disclosure | cli/main.py path handling | mitigate | `path.is_file()` validation + re-prompt loop before any file-open; only user-supplied local paths are read and the tool is a local CLI with no privilege boundary; unprocessable input exits 1 with a contained message, never a traceback (no path/stack leakage) |
| T-01-05 | Tampering | parser/ingest (crafted chat content) | accept | Phase 1 only counts messages — no content rendering exists yet, so no injection surface; parser robustness, size caps, and skip-counters are Phase 2; HTML escaping is Phase 3 (jinja2 autoescape per STACK decision) |
| T-01-06 | Tampering | installed package contents | mitigate | QUAL-04 test scans the installed package tree for exec(code / unsafe_allow_html / import streamlit / import plotly and fails the suite if any appear (Test 7); web-app code deleted in plan 01 Task 2 |
| T-01-07 | Denial of service | Windows console (cp1252) | mitigate | `sys.stdout/stderr.reconfigure(encoding="utf-8", errors="replace")` bootstrap as the first statement of main() (research Pitfall 5 — default CMD encoding must never kill output or error messages); ASCII-first CLI output |
| T-01-SC | Tampering | pip installs (typer, rich, plotext, hatchling + [dev] extra: pytest, pytest-cov, ruff) | mitigate | Blocking-human legitimacy checkpoint approved in plan 01 Task 3 before this plan's `pip install -e .`; all other base deps were already declared in the repo's requirements.txt.
